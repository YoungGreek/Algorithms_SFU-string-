Поиск подстрок в строке или файле (алгоритм Бойера–Мура–Хорспула)

Параметры, которые нужно указать для запуска из консоли:
--str_or_file (целевая строка или путь к файлу)
--sub_str (подстрока для поиска, можно указать несколько: python main.py --sub_str "sub_str" ... --sub_str "sub_str_n")
--case_sensitivity (чувствительность к регистру: 0 - не важно 1 - важно)
--method (метод поиска: first - с начала last - с конца)
--count (максимум вхождений, которые нужно найти)
